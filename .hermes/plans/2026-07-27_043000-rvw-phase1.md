# rvw Phase 1 Implementation Plan

> **For Hermes:** Use subagent-driven-development to implement task-by-task. Route implementation per `dev-delegation` (backend executor = `codex`, see `~/.hermes/executors/README.md`).

**Goal:** Ship the `rvw` skeleton with a working DISCOVER stage — a real `codex exec` lane that returns schema-valid findings for a real diff.

**Architecture:** Python 3.11+ / uv package / Typer CLI / Pydantic v2 models. Registry-driven layer activation (ADR-002), hunk-anchored findings (ADR-004), replicated single-wave dispatch (ADR-006). Phase 1 stops before MERGE/ADJUDICATE/REPORT.

**Tech Stack:** uv, Typer, Pydantic v2, ruff, pyright strict, pytest. External: `codex` CLI 0.145.0+, `gh`, `git`.

**Decisions:** `../DECISIONS.md` ADR-001 … ADR-014

```python
# src/rvw/schema.py
"""Wire and disk models. See DECISIONS.md ADR-003, ADR-004."""

from __future__ import annotations

from enum import StrEnum
from typing import Any

from pydantic import BaseModel, ConfigDict, Field

SCHEMA_VERSION = 1


class Severity(StrEnum):
    BLOCKER = "blocker"
    WARNING = "warning"
    SUGGESTION = "suggestion"


class Verdict(StrEnum):
    CONFIRMED = "CONFIRMED"
    REJECTED = "REJECTED"
    UNCERTAIN = "UNCERTAIN"


class Tier(StrEnum):
    BASE = "base"
    PROJECT = "project"
    SCOPE = "scope"
    DYNAMIC = "dynamic"


class Finding(BaseModel):
    """One defect claim from one lane. Adjudication unit (ADR-003 D1)."""

    model_config = ConfigDict(extra="forbid")

    schema_version: int = Field(default=SCHEMA_VERSION, ge=1)
    rule_id: str
    file: str
    hunk_id: str
    line: int | None = None
    severity: Severity
    body: str
    anchorable: bool = False
    verdict: Verdict | None = None
    verdict_reason: str | None = None


class LaneOutput(BaseModel):
    """Strict JSON contract a runtime must satisfy (ADR-004 D5)."""

    model_config = ConfigDict(extra="forbid")

    verdict: str
    findings: list[Finding] = Field(default_factory=list)


def finding_schema() -> dict[str, Any]:
    return Finding.model_json_schema()


def lane_output_schema() -> dict[str, Any]:
    return LaneOutput.model_json_schema()
```

**Step 4:** `uv run pytest tests/test_schema.py -v` → 3 passed

**Step 5:** `git add -A && git commit -m "feat: core finding/lane-output models (ADR-003, ADR-004)"`

### Task 9: Hunk parser

**Objective:** Deterministic `hunk_id` from a unified diff, plus `anchorable` determination.

**Files:** Create `src/rvw/hunks.py`, `tests/test_hunks.py`

```python
def parse_hunks(diff: str) -> list[Hunk]: ...
def hunk_for_line(hunks: list[Hunk], file: str, line: int) -> Hunk | None: ...
def is_anchorable(hunks: list[Hunk], file: str, line: int) -> bool: ...
```

`hunk_id` format: `<file>@@-<old_start>,<old_count>+<new_start>,<new_count>@@`

Tests must cover:
- multi-hunk single file
- multi-file diff
- a line inside a hunk but on a context (unchanged) line → **not** anchorable
- a line outside every hunk → `hunk_for_line` returns `None`, finding keeps `file:*` and stays in the report (ADR-004 D6)
- new-file and deleted-file diffs

**Pitfall:** GitHub rejects inline anchors outside the diff with HTTP 422. Determining this locally is exactly what prevents that (ADR-012 pitfall 1).

### Task 10: Codex runtime adapter

**Objective:** Execute one lane against one target and return a validated `LaneOutput`.

**Files:** Create `src/rvw/runtimes/codex.py`, `src/rvw/runtimes/__init__.py`, `tests/test_runtime_codex.py`

Command shape (measured working, codex-cli 0.145.0):

```bash
timeout --foreground --signal=TERM --kill-after=30s <deadline>s \
  codex exec --sandbox read-only --color never \
    -c features.multi_agent=false \
    -c features.collaboration_modes=false \
    --output-schema <lane-schema.json> \
    -o <run-dir>/out.json \
    - < <run-dir>/prompt.md
```

Validity contract (ADR-004 D5 / ADR-006 D5) — ALL must hold or the run is `INVALID`:
1. process exit code 0
2. `out.json` exists and is non-empty
3. parses as JSON and validates against `LaneOutput`
4. the run log contains a terminal completion marker

**INVALID must never be promoted to PASS.** An invalid replica is discarded; only all-3-invalid triggers a retry.

Unit tests stub the subprocess. One `@pytest.mark.live` test performs a real invocation and is deselected by default (`-m "not live"`).

### Task 11: Single-wave dispatcher

**Objective:** Run `lanes x replicas` concurrently in one wave, heavy-first.

**Files:** Create `src/rvw/dispatch.py`, `tests/test_dispatch.py`

```python
async def dispatch(
    plan: Plan,
    *,
    replicas: int = 3,
    concurrency: int = 16,
    on_progress: Callable[[RunStatus], None] | None = None,
) -> list[RunResult]: ...
```

Rules from ADR-006:
- ONE wave; no inter-lane dependency
- LPT ordering: `cost: heavy` dispatches first
- `concurrency` default 16 (highest measured; **do not raise without re-measuring** — ADR-006 pitfall 2)
- no hedging
- a failed replica is recorded, not retried, unless all replicas of that lane failed

Tests use a fake runtime with scripted delays; assert ordering (heavy first), max in-flight never exceeds `concurrency`, and that one failing replica does not fail the lane.

## Risks and open questions

1. **36 concurrent runs is beyond the measured range.** ADR-006 measured up to 16. Task 11 caps `concurrency` at 16 and queues the remainder. Re-measure before raising.
2. **Live tests are non-deterministic** (5 ± 1 findings over 8 identical runs). Assertions must be written as "contains the known defect", never as exact counts.
3. **`hunk_id` is head-dependent.** Findings are only valid for the head that produced them; Phase 4's publish guard must re-verify head identity before posting.
4. **Sweep prompt injection of other lanes' rule lists is unproven at scale.** It worked with 5 rules in the probe. With 12 lanes the "already covered" list gets long and may dilute the instruction — watch the `other` ratio in Phase 5's `doctor`.
5. **Adjudicator shares the discovery runtime** (ADR-007 pitfall 1). If Phase 3 shows FP leakage, pin the adjudicator to a different runtime.
